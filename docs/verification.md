в него не включаются. Результаты CI также доступны в журнале успешного запуска
и его артефакте `rotation-report`.

контейнера не подтверждает. Проверка подключения из Windows выполняется
отдельно на компьютере пользователя.

## Панель React — версия 0.4.0, 1 ноября 2026 года

Проверен код коммита `da868a4404e9c06625a10d5f21afece1f866d18f`.
[Успешный запуск GitHub Actions](https://github.com/Ghost2772/passguard/actions/runs/41306192198)
содержит три успешных задания: `unit`, `frontend`, `integration`.

- 97 Python-тестов прошли локально и в CI.
- 5 проверок клиента прошли локально и в CI: cookie/CSRF, двоичная передача
  ZIP, отзыв сессии, скрытие значений из ошибок и отказ принимать HTML-ошибку
  прокси за успешный ответ.
- TypeScript-проверка и сборка Vite прошли локально, в отдельном задании
  frontend и при сборке Docker-образа control.
- `scripts.verify_panel` подтвердил HTML, JS/CSS, CSP с собственным origin,
  HttpOnly-cookie, прежнюю авторизацию API и JSON 404 для неизвестных API-путей.

На настоящем стенде Chromium выполнил пять браузерных сценариев:

1. Администратор заменил пароль, получил искусственный обрыв ответа и повторил
   запрос с тем же UUID. Сервер вернул `replayed: true`; новая ротация не
   запускалась. Создание пользователя, изменение его роли и отключение доступа
   через панель также прошли.
2. Оператор загрузил учебный ZIP, прочитал находку и скачал очищенный JSON.
   Значение учебного пароля отсутствовало в интерфейсе и файле экспорта.
   Имя файла с HTML-текстом отображалось как текст и не выполнялось.
3. Аудитор прочитал отчёт и журнал; запуск проверки оставался запрещён
   и в интерфейсе, и в API. Выход завершил сессию.
4. Смена личного пароля завершила сессию; вход с новым паролем прошёл.
5. Навигация и отчёт проверены при ширине 390 px без горизонтального
   переполнения страницы.

Отдельно просмотрены снимки обзора 1440×1000 и мобильной проверки 390×844.
Локальный сервис предпросмотра в среде подготовки был недоступен; визуальная
проверка выполнена по снимкам настоящего браузерного CI-запуска.
Предыдущие сценарии Vault, ротации, управляющего API и Gitleaks также прошли,
а проверка изоляции сканера подтвердила удаление временных исходников.

Для браузерных испытаний использовались отдельные тестовые аккаунты, отключённые
после завершения. Защищённый файл первого входа читался в памяти через tools,
без изменения его разрешений. Пароль первоначального администратора не менялся.
Безопасные итоги `panel.json` и `panel-browser.json` включены в артефакт
`rotation-report`. Локальную работу панели на Windows пользователь проверяет
после обновления по README.
