# Проверки подготовленной версии

Дата подготовки: 31 октября 2026 года. Версия первого этапа: `0.1.0`.

| Проверка | Результат при подготовке |
| --- | --- |
| Модульные проверки Python 3.12.14 | 27 пройдено |
| Синтаксис Python | Пройдено |
| Синтаксис YAML, ссылки на локальные конфигурации | Пройдено |
| Синтаксис shell-скриптов | Пройдено |
| Полный запуск Docker Compose | Не выполнен: Docker в среде подготовки недоступен |
| Живая ротация Vault → PostgreSQL | Не выполнена: требуется запуск контейнеров |
| GitHub Actions | Workflow подготовлен, запуск ещё не подтверждён |

Модульные проверки подтверждают поведение кода при заданных ответах зависимостей.
Они не доказывают совместимость Docker-образов или фактическую смену пароля
в PostgreSQL. Эти свойства проверяет `scripts.verify_rotation` на живом стенде.

В среде подготовки тестовый клиент FastAPI выдал предупреждение о будущем
переходе Starlette с httpx на httpx2. На результаты 27 проверок оно не повлияло;
текущая версия клиента остаётся работоспособной.

Для получения фактического протокола испытания выполни команды запуска из
README и `docker compose run --rm tools python -m scripts.verify_rotation`.
Только успешный результат этой команды подтверждает выполнение центрального
испытания курсовой. После отправки исходников в GitHub то же испытание
запускается отдельным заданием GitHub Actions.
