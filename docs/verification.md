| GitHub Actions | Оба задания завершились успешно; сохранён артефакт `rotation-report` |

Модульные проверки подтверждают поведение кода при заданных ответах зависимостей.
Совместимость Docker-образов и фактическую смену пароля в PostgreSQL отдельно
подтвердил `scripts.verify_rotation` на настоящих контейнерах в GitHub Actions.
Локально в среде подготовки Docker недоступен; запуск на компьютере пользователя
в этот протокол не входит.

В среде подготовки тестовый клиент FastAPI выдал предупреждение о будущем
переходе Starlette с httpx на httpx2. На результаты 30 проверок оно не повлияло;
текущая версия клиента остаётся работоспособной.

Для повторения испытания выполни команды запуска из README и
`docker compose run --rm tools python -m scripts.verify_rotation`.
Безопасный отчёт сохранится в `reports/rotation.json`. Пароли и токены
в него не включаются. Результаты CI также доступны в журнале успешного запуска
и его артефакте `rotation-report`.

## Проверка публикации порта — 1 ноября 2026 года

В коммите `04d8110f768048c650343fc078b701502cf4b934` приложение подключено
к отдельной сети `web` для публикации HTTP-порта. Доступ из контейнера к
PostgreSQL и Vault выполняется через изолированную сеть `backend`.

[Повторный успешный запуск GitHub Actions](https://github.com/Ghost2772/passguard/actions/runs/41297004827)
подтвердил 30 модульных проверок и полный сценарий ротации до и после
перезапуска Vault. Дополнительный HTTP-запрос с Linux-хоста Docker к
`http://127.0.0.1:8001/ready` вернул `{"status":"ready"}`.

Эта проверка охватывает публикацию порта, которую проверка готовности внутри
контейнера не подтверждает. Проверка подключения из Windows выполняется
отдельно на компьютере пользователя.
